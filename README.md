# The Kinda Short Haven Jumpstart Platformer

This is a simple platformer that I've made to qualify for co-hosting a local Hack Club Haven through the free time I had during school breaks and such. It's about a few minutes long, features a green hacker style similar to [that one WebOS I made for a Discord server](https://os.fatethroughdifferenteyes.com/), and a little rectangle you play as that's only there because I thought it'd look cool if it was just on that singular spot on the screen the entire time and didn't have any actual player character.

Also, the rectangle can dash.  
Like in Celeste.  
Yeah.  
I dunno what else to say.

## Controls

WASD/Arrow Keys - Move  
Z/Space - Jump  
X/Shift + Direction - Dash  
That's kinda it.
